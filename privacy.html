Privacy Policy

Last updated October 6, 2026

Quran Horizons is a single-operator channel. This integration moves video files from the operator's own library to the operator's own TikTok account, and nothing else.

01 What's collected, and why

DataSourceUsed for
TikTok OAuth access & refresh tokensTikTok's own authorization flow, after the operator signs in and approves the requested scopesAuthenticating each video upload to the operator's TikTok account
Basic TikTok profile info (display name, avatar, account stats)TikTok's user.info.basic / user.info.profile scopesConfirming uploads are reaching the correct account
Video files, titles, and descriptionsPrepared locally by the operator before each uploadThe content of the post itself

02 What's never collected

No data from TikTok viewers, followers, or any account other than the operator's own. No payment information. No device identifiers, location, or contact lists. The integration doesn't read TikTok comments, messages, or any other account's content.

03 Storage and retention

OAuth tokens are stored locally, on the operator's own machine, and used only to authorize uploads. They're never transmitted anywhere except to TikTok's own API endpoints. A token is replaced whenever the operator re-authorizes, and can be revoked at any time from TikTok's account settings.

04 Sharing

Nothing collected here is sold, rented, or shared with any third party. The only data transfer this integration performs is the upload itself вЂ” video, title, and description вЂ” sent directly to TikTok's Content Posting API under the operator's own authorization.

05 Changes to this policy

If this integration starts collecting anything beyond what's listed above, this page will be updated first, with a new date at the top.
